# CSV to MongoDB Loader

Программа для автоматизированной загрузки данных из CSV-файла в базу данных MongoDB с обработкой дублирующих записей и фиксацией источника данных.

## Возможности 

- Чтение и парсинг CSV-файла
- Подключение к MongoDB с параметрами из конфигурационного файла
- Проверка записей на дубликаты по заданным ключевым полям
- Дозапись новых данных в случае дубликатов
- Фиксация источника данных для каждой записи

## Структура проекта
- `Config.py` — конфигурационный файл, содержащий:
 - Параметры подключения к MongoDB
 - Пути к CSV-файлам
 - Настройки фильтрации дубликатов
- `Loader.py` — основной модуль с бизнес-логикой:
 - Чтение CSV-файла
 - Проверка на дубликаты
 - Обновление или вставка записей
 - Добавление поля с источником данных
- `data.csv` — пример CSV-файла, подаваемого на вход программе

## Как использовать

1. Укажите параметры подключения и настройки в `Config.py`.
2. Подготовьте CSV-файл и укажите путь к нему в конфигурации.
3. Запустите `Loader.py`

## Требования
- Python 3.x
- Библиотеки:
  - `pymongo`
  - `pandas`

 ## Преиущества

 -**Гибкая настройка** через `Config.py`
 -**Сохранение данных** при наличии дубликатов
 -**Прозрачный аудит** благодаря полю с источниками данных
